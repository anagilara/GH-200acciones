# GH-200acciones

Aplicacion web de administracion de usuarios en Node.js.

## Estructura solicitada
- `/src` -> codigo
- `/test` -> pruebas unitarias
- `/docs` -> documentacion
- `/package` -> paquete para calcular la antiguedad como cliente

## Inicio rapido
```bash
npm start
```

Luego abre en navegador:

```text
http://localhost:3000
```

## Pruebas
```bash
npm test
```

Consulta la documentacion completa en `/docs/README.md`.
